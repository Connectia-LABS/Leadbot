# Guía de demo para portfolio

Esta guía ayuda a presentar LeadBOT en entrevistas, reuniones comerciales o portfolio sin revelar información sensible.

## Demo sugerida

### 1. Problema

Mostrar una conversación típica de WhatsApp donde un cliente consulta fuera de horario o entrega información desordenada.

Mensaje clave:

> LeadBOT convierte conversaciones informales en oportunidades comerciales organizadas.

### 2. Atención con IA

Mostrar cómo el bot responde de forma contextual, pide un dato faltante y evita repetir preguntas.

Aspectos a destacar:

- continuidad conversacional;
- tono configurable;
- uso de conocimiento del negocio;
- una pregunta clara por turno.

### 3. Calificación del lead

Mostrar el paso de conversación a lead calificado.

Aspectos a destacar:

- necesidad detectada;
- datos de contacto;
- temperatura comercial;
- próximo paso recomendado.

### 4. Derivación humana

Mostrar que, cuando el caso está listo, el bot deriva y deja de insistir.

Mensaje clave:

> La automatización ayuda hasta donde aporta valor; después entrega el caso al equipo humano.

### 5. Seguimiento comercial

Mostrar el tablero de leads o seguimiento para explicar cómo el equipo prioriza acciones.

## Capturas recomendadas

- Panel de inbox con conversación de ejemplo.
- Vista de configuración del bot.
- Base de conocimiento cargada con datos genéricos.
- Tabla de leads sin datos reales.
- Seguimiento comercial con registros ficticios.
- Módulos activos por tenant.

## Qué evitar en una demo pública

- Datos reales de clientes.
- Tokens, credenciales o pantallas de configuración sensible.
- URLs internas.
- Prompts completos.
- Reglas de scoring detalladas.
- Paneles con infraestructura o logs productivos.
