# Alcance público y límites de divulgación

LeadBOT es un producto propietario de Connectia-LABS. Este repositorio existe para mostrar el producto en un contexto profesional sin publicar activos sensibles.

## Permitido en este repositorio

- Descripción del producto.
- Capturas con datos ficticios o anonimizados.
- Arquitectura conceptual.
- Casos de uso.
- Tecnologías utilizadas.
- Decisiones de diseño.
- Resultados o aprendizajes generales.
- Fragmentos pequeños y aislados, si no revelan lógica crítica.

## Excluido de este repositorio

- Código completo del backend.
- Código completo del frontend.
- Prompts productivos.
- Lógica de scoring.
- Credenciales y variables de entorno.
- Esquema completo de base de datos.
- Configuración de infraestructura.
- Webhooks, endpoints internos y reglas comerciales.
- Integraciones que revelen cómo replicar el producto.
- Datos reales de clientes, leads o conversaciones.

## Criterio de publicación

Todo material público debe responder sí a estas preguntas:

1. ¿Puede entenderse el valor del producto sin copiar su implementación?
2. ¿No contiene secretos, credenciales ni configuración operativa?
3. ¿No revela reglas comerciales críticas?
4. ¿No expone datos reales de clientes?
5. ¿Sirve para portfolio, entrevista o presentación comercial?

Si alguna respuesta es no, el material no debe publicarse.
