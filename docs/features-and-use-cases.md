# Funcionalidades y casos de uso

LeadBOT está pensado para negocios que necesitan responder más rápido, ordenar conversaciones y convertir consultas en oportunidades comerciales.

## Funcionalidades

### Atención conversacional con IA

El bot interpreta la consulta del usuario, mantiene contexto de la conversación y responde según la información disponible del negocio.

### Base de conocimiento

Cada tenant puede cargar información del negocio para que las respuestas sean más precisas y alineadas a su operación.

### Calificación de leads

El sistema detecta intención, necesidad, datos de contacto, temperatura comercial y estado de avance. El objetivo es reducir conversaciones perdidas y facilitar seguimiento.

### Derivación humana

Cuando la conversación llega a un punto accionable, LeadBOT puede derivar el caso a una persona del equipo. Esto evita que el bot siga insistiendo cuando ya corresponde atención humana.

### Seguimiento comercial

Los leads pueden visualizarse en un flujo de seguimiento para priorizar contactos, oportunidades y próximas acciones.

### Servicios y turnos

Para negocios de servicios, el producto puede trabajar con prestaciones, disponibilidad y solicitudes de agenda cuando el módulo está activo.

### Comercio

Para negocios con catálogo, LeadBOT puede orientar consultas sobre productos, stock y pedidos cuando el módulo de comercio está activo.

## Casos de uso

| Tipo de negocio | Ejemplo de uso |
| --- | --- |
| Estudios profesionales | Recepción de consultas, toma de datos y derivación al equipo. |
| Agencias y servicios B2B | Clasificación de necesidad, canal de captación y objetivo comercial. |
| Comercios | Consultas de catálogo, disponibilidad y pedidos. |
| Clínicas o centros de atención | Orientación inicial, servicios disponibles y solicitudes de turno. |
| Equipos comerciales | Centralización de WhatsApp, scoring y seguimiento. |

## Resultado buscado

- Menos consultas sin responder.
- Mejor tiempo de primera respuesta.
- Menos repetición de preguntas.
- Leads más ordenados.
- Mayor claridad para el equipo humano.
- Mejor trazabilidad comercial.
