# Capturas y material visual

Este repositorio puede incluir capturas del producto siempre que estén preparadas para portfolio y no expongan datos reales ni configuración sensible.

## Capturas recomendadas

- Dashboard general con métricas ficticias.
- Inbox con una conversación de ejemplo anonimizada.
- Configuración visual del bot sin claves ni tokens.
- Base de conocimiento con contenido genérico.
- Vista de leads con nombres y teléfonos ficticios.
- Seguimiento comercial con oportunidades de prueba.
- Pantalla de módulos activos por tenant.

## Reglas para publicar imágenes

- Usar datos ficticios o anonimizados.
- Tapar teléfonos, correos, tokens, IDs internos y URLs privadas.
- Evitar pantallas de infraestructura, logs o configuraciones operativas.
- No mostrar prompts completos ni reglas internas.
- Preferir imágenes que expliquen valor de producto, no implementación.

## Nombres de archivo sugeridos

Si se agregan capturas en el futuro, usar nombres descriptivos:

- `dashboard-overview.png`
- `inbox-demo.png`
- `lead-qualification.png`
- `commercial-follow-up.png`
- `modules-settings.png`

Las imágenes deberían guardarse en una carpeta `assets/screenshots/` y referenciarse desde el README sólo después de revisar que no contengan información sensible.
